# The Crown of Aveloria – Text-Based RPG Game

## Project Description
The Crown of Aveloria is a text-based role-playing game (RPG) built using Python.
In this game, the player takes on the role of a hidden princess who must choose between accepting her royal destiny or forging her own path.
The story evolves based on the player's choices, leading to multiple unique endings.

## Features

- Interactive story with multiple choices
- Different story paths and outcomes
- Role-playing as a princess and future queen
- Warrior and diplomacy-based gameplay options
- Alternate storyline with runaway path
- Multiple endings based on decisions

## Technologies Used
### Python 3.x
### Standard input/output (console-based interaction)

## How to Play
- Run the Python script
- Enter your name when prompted
- Follow the story and make choices by entering:
- 1 or 2
- Explore different paths and endings

## Example Gameplay
- 🌸 Welcome to 'The Crown of Aveloria' 🌸
  Enter your name: Arya

- 👑 The guard kneels before you.
' Princess Arya, you are the rightful heir to the throne!'

- Do you:
 1. Accept your destiny
 2. Refuse and run away
